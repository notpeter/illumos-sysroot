## Contents, shims, and runtime

The archive contains the required headers, crt objects, GSS libraries, and
four shim objects and excludes every directory forbidden by the release plan.
Both the 20181213 gate and published v2 archive lack `libssp_ns.a`, so v3
preserves that absence.
